# The original THOTH

Preserved source and Xcode projects from Jesse Sullivan's 2017 college experiment. The C module demonstrated Python integration through a Fibonacci function; the Python script read a tiny table and displayed a star image. They require their original obsolete environment and are not the new application entry point.

The original commits remain ancestors of THOTHv2. Generated macOS object files and interpreter-specific binaries are removed from the modern checkout; the original historical commits retain them.
